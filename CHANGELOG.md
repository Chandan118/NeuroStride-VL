# NeuroStride-VL Changelog
# ========================

## [0.1.0] - 2026-04-17

### New Features

- Initial release
- MuJoCo bipedal robot simulation environment
- PPO/SAC reinforcement learning training modules
- Qwen-2-VL vision-language model integration
- ROS2 commander-executor distributed architecture
- TensorRT model quantization tools
- One-command install scripts (supports Mac M2 Pro and Jetson Orin Nano)
- Complete configuration system and deployment scripts
- Comprehensive documentation and tutorials

### Technology Stack

- **Simulation**: MuJoCo 2.3+
- **RL Framework**: Stable-Baselines3
- **VLM**: Qwen/Qwen-VL-2B-Chat
- **Middleware**: ROS2 Humble
- **Edge Optimization**: TensorRT 8.6+
- **Training Framework**: PyTorch 2.0+

### Supported Hardware

- MacBook M2 Pro (development & simulation)
- NVIDIA Jetson Orin Nano (edge deployment)
