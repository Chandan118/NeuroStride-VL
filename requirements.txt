# Platform-Specific Notes
# ========================
#
# Mac M2 Pro (Development Machine):
# --------------------------------
# 1. Install Miniforge (ARM64 Python):
#    curl -L -O "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-MacOSX-arm64.sh"
#    bash Miniforge3-MacOSX-arm64.sh
#
# 2. Install PyTorch with MPS support:
#    conda install pytorch torchvision pytorch-cuda=11.8 -c pytorch -c nvidia
#    # OR use pip with metal backend:
#    pip install torch torchvision --index-url https://download.pytorch.org/whl/nightly/cpu
#
# 3. Install MuJoCo:
#    conda install -c conda-forge mujoco
#
# 4. Install ROS2 (via Docker or separate Linux machine):
#    ROS2 is not natively supported on macOS. Use Docker or run on Jetson.
#
# Jetson Orin Nano (Edge Deployment):
# ------------------------------------
# 1. Flash JetPack 6.0 (includes Ubuntu 22.04, CUDA 11.8, cuDNN, TensorRT)
#
# 2. Install system dependencies:
#    sudo apt update
#    sudo apt install python3-pip python3-dev libopenblas-dev libomp-dev
#    sudo apt install ros-humble-desktop  # Full ROS2 installation
#
# 3. Install PyTorch for Jetson (pre-built wheel):
#    wget https://nvidia-ai-iot.github.io/torch2trt/install_torch.sh
#    sudo bash install_torch.sh
#    # OR download from NVIDIA PyTorch for Jetson GitHub releases
#
# 4. Install TensorRT and torch2trt:
#    sudo apt install python3-libnvinfer-dev libnvinfer-dev python3-libnvinfer
#    pip install torch2trt
#
# 5. Install remaining Python packages:
#    pip3 install -r requirements.txt
#
# Docker Alternative (Cross-Platform):
# --------------------------------------
# Use Docker containers to ensure consistent environments:
# - neurostridevl/dev:latest (M2 Pro development)
# - neurostridevl/jetson:latest (Orin Nano cross-compilation)
#
# See docker/Dockerfile.dev and docker/Dockerfile.jetson
